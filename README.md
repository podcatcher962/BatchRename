## English
### Overview
BatchRename is a batch file renamer with 4 modes: sequence, date, replace, regex. Preview before apply, undo support.

### Features
- 📁 Multi-file selection
- 🔢 Sequence: prefix + start number + suffix
- 📅 Date: auto-date with format options
- 🔄 Replace: find & replace in filename
- 🔍 Regex: pattern matching
- 👁 Preview · ✅ Apply · ↩ Undo
- 🌐 Bilingual · 🔒 Pure local
